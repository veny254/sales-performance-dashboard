# 📊 Sales Performance Dashboard

An interactive business intelligence dashboard built with Python, Pandas, Plotly, and Streamlit.

## 🚀 Live Demo

[Open the Live Dashboard](https://veny254-sales-dashboard.streamlit.app/)

## 📌 Overview

This project transforms sales data from CSV or Excel files into an interactive business intelligence dashboard.

Users can upload their own sales dataset, filter the data, analyze business performance, and explore interactive visualizations.

## ✨ Features

- Upload CSV and Excel files
- Automatic data cleaning and validation
- Data quality summary
- Date range filtering
- Region filtering
- Category filtering
- Product filtering
- Total sales analysis
- Profit analysis
- Interactive Plotly charts
- Sales trend analysis
- Product performance analysis
- Export filtered data to CSV
- Export filtered data to Excel

## 📊 Dashboard Metrics

- Total Sales
- Total Profit
- Number of Orders
- Number of Products
- Profit Margin
- Average Order Value

## 📈 Visualizations

- Sales by Region
- Sales by Category
- Profit by Category
- Sales Trend
- Sales by Product
- Profit by Region
- Sales vs Profit by Region
